# Data Management

## Purpose
This directory stores the datasets used in the Hindupur Political Intelligence Dashboard.

## Data Categories

### Raw Data
Original data collected from newspapers, government portals, election records and other documented sources.

### Processed Data
Cleaned, standardised and structured datasets ready for analysis.

### Reference Data
Verified geographical information, constituency lists and other reference datasets.

## Data Management Principles
- Record the original source of every dataset.
- Maintain collection dates.
- Preserve original data wherever possible.
- Document data cleaning procedures.
- Distinguish verified facts from reported claims.
- Avoid publishing personal or confidential information.
