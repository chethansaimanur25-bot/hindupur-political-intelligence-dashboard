# Raw Data

## Purpose

This directory stores original and unmodified data collected for the Hindupur Political Intelligence Dashboard.

## Data Sources

- Government reports
- Election records
- Newspaper publications
- Official constituency records
- Public development datasets

## Data Management Rules

- Preserve original source files.
- Record source URLs and collection dates.
- Do not overwrite original datasets.
- Maintain source attribution.
